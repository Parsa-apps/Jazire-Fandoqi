# فایل‌های پیشخان مایکت — جزیره فندقی

متن آماده‌ی کپی در `STORE_LISTING.md` است.

## 🔴 اول از همه: قیمت نصب = رایگان

مدل درآمدی ما **فقط پرداخت درون‌برنامه‌ای** است؛ نصب باید رایگان باشد.
این تنظیم در APK نیست و فقط از پنل مایکت تغییر می‌کند:

```
برنامه‌ها → مدیریت برنامه → اطلاعات پایه → تعیین قیمت → رایگان
```

اگر این فیلد روی مبلغ تنظیم شده باشد، مایکت پیش از دانلود از کاربر پول
می‌گیرد. راهنمای کامل و گام‌به‌گام در
`docs/MYKET_FREE_INSTALL_IAP_FA.md` است.

## تصاویر

برای مایکت از همان مجموعه نهایی بازار استفاده کنید؛ فایل‌ها عمودی، `1080×1920` و بر پایه اسکرین‌شات واقعی برنامه‌اند:

| فیلد | فایل |
|---|---|
| آیکون | `store/bazaar/icon_512.png` |
| اسکرین‌شات‌ها | هشت فایل شماره‌دار `store/bazaar/upload/1_home.png` تا `8_safe.png` |

ترتیب آپلود تصاویر:

1. یادگیری فارسی با بازی و قصه
2. تمرین واقعی شنیداری و املا
3. بازی‌های هدفمند
4. قصه‌های تعاملی و شنیدنی
5. کارنامه رشد و پیشرفت
6. مأموریت‌های روزانه
7. پروفایل کودک
8. محیط امن و بدون تبلیغ

## چیزهایی که فقط مایکت دارد / ندارد

- **سرصفحه ۵×۲:** مایکت ندارد (فقط بازار). اسکرین‌شات و آیکون کافی است.
- **ویدیو:** مایکت از ویدیوی معرفی پشتیبانی می‌کند (اختیاری).
- **پرداخت:** درگاه مایکت با `Myket Billing Client 1.19` در کد متصل است؛
  محصول `full_version` (دائمی) باید در پنل توسعه‌دهنده مایکت ساخته شود و
  کلید RSA همان حساب در `android/billing.properties` (`myketRsaPublicKey`)
  قرار گیرد. کلید باید **دقیقاً** همان رشتهٔ Base64 پنل باشد: یک خط، بدون
  فاصله و بدون چسبیدن دو کلید به هم. بیلد release کلید خراب را رد می‌کند.
- **خروجی مخصوص مایکت:** حتماً با `flutter build apk --flavor myket --release`
  بسازید و فایل `app-myket-release.apk` را آپلود کنید. خروجی flavor مایکت
  مجوز پرداخت رقیب (`PAY_THROUGH_BAZAAR`) را از manifest نهایی حذف می‌کند.
- **لینک حریم خصوصی:** اجباری است؛ از URL هاست‌شده‌ی `PRIVACY_POLICY_FA.md`.

## ترتیب پیشنهادی تکمیل پیشخان

1. **قیمت نصب → رایگان** (بدون این، مایکت برای دانلود پول می‌گیرد)
2. عنوان + توضیح کوتاه + توضیحات کامل (از `STORE_LISTING.md`)
3. دسته‌بندی «کودک / آموزشی» + رده‌بندی سنی
4. آیکون + ۸ اسکرین‌شات، با ترتیب بالا
5. لینک حریم خصوصی
6. ساخت محصول `full_version` (دائمی) + تأیید کلید RSA
7. تست سندباکس (خرید/لغو/بازیابی)
