## ترتیب مجموعهٔ فعلی (آرشیوی — فقط برای شناسایی فایل‌ها)

فایل‌های موجود در پوشه `store/bazaar/upload/` با این نام و پیام ساخته شده‌اند:

1. `1_home.png` — یادگیری فارسی با بازی و قصه
2. `2_learning.png` — تمرین واقعی شنیداری و املا
3. `3_games.png` — بازی‌های هدفمند
4. `4_stories.png` — قصه‌های تعاملی و شنیدنی
5. `5_progress.png` — کارنامه رشد و پیشرفت
6. `6_missions.png` — مأموریت‌ها و جایزه‌های روزانه
7. `7_profile.png` — پروفایل و آواتار کودک
8. `8_safe.png` — محیط امن و بدون تبلیغ

این هشت فایل آرشیوی برای نسخهٔ هدف در **هیچ‌یک از دو فروشگاه** قابل استفاده
نیستند. مجموعهٔ تازهٔ عمودی (پس از برداشت از نسخهٔ هدف) می‌تواند در هر دو
فروشگاه به کار رود و نیازی به کپی جداگانه ندارد؛ مایکت سرصفحهٔ ۵×۲ ندارد.

## ساخت دوباره تصاویر

منبع خام در `assets/screeen/` نگهداری می‌شود. توجه: `SLIDES` ابزار در حال
حاضر هنوز به همان برداشت‌های `Screenshot_20260816_*` (نسخهٔ ۶.۲.۶) اشاره
می‌کند؛ اجرای ابزار پیش از جایگزینی برداشت‌ها و به‌روزرسانی `SLIDES` طبق
`../myket/SCREENSHOTS_PLAN_FA.md` فقط همان مجموعهٔ قدیمی را بازتولید می‌کند.
برای بازسازی خروجی‌ها پس از آن به‌روزرسانی:

```bash
python3 -m venv .venv
.venv/bin/pip install -r tools/requirements-store-assets.txt
.venv/bin/python tools/build_store_screenshots.py
```

اسکریپت فایل‌های قدیمی پوشه آپلود را حذف می‌کند تا تصویر اضافه‌ای اشتباهی در پیشخان بارگذاری نشود.
