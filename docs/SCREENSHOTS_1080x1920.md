## مشخصات خروجی

- اندازه: `1080×1920` پیکسل
- فرمت: PNG بهینه‌شده
- جهت: عمودی
- تعداد: ۸ تصویر
- رابط کاربری: تصویر واقعی برنامه داخل قاب گوشی
- تایپوگرافی: Vazirmatn و راست‌چین فارسی
- ترتیب آپلود: مطابق شماره ابتدای نام فایل

## بازسازی

```bash
python3 -m venv .venv
.venv/bin/pip install -r tools/requirements-store-assets.txt
.venv/bin/python tools/build_store_screenshots.py
```
