# 📸 فاز ۷۴ — اسکرین‌شات و آیکون استور

## وضعیت نهایی

۸ اسکرین‌شات عمودی `1080×1920` بر پایه تصاویر واقعی برنامه آماده شده‌اند و از مسیر `store/bazaar/upload/` برای هر دو فروشگاه بازار و مایکت قابل بارگذاری هستند.

| # | صفحه واقعی | متن بزرگ فارسی روی تصویر |
|---|---|---|
| ۱ | خانه؛ کارتون‌ها و قصه‌ها | «دنیایی از بازی و یادگیری» |
| ۲ | نقشه آکادمی فارسی و ادبیات | «آموزش فارسی، قدم‌به‌قدم» |
| ۳ | نقشه بازی‌ها | «بازی کن، فکر کن، جایزه بگیر» |
| ۴ | قصه‌خانه | «قصه‌های شنیدنی کودکانه» |
| ۵ | کارنامه پیشرفت تحصیلی | «رشد کودک را دنبال کنید» |
| ۶ | تالار افتخارات و مأموریت‌ها | «هر روز یک مأموریت تازه» |
| ۷ | پروفایل و آواتار کودک | «دنیای مخصوص هر کودک» |
| ۸ | صفحه معرفی جزیره | «شاد، امن و بدون تبلیغ» |

## اصول اجراشده

- یک پیام فارسی بزرگ و خوانا در هر تصویر
- نمایش رابط کاربری واقعی به‌جای ماکاپ ساختگی
- حضور برند فندقی در نشان بالای همه تصاویر
- رنگ‌بندی شاد و متمایز با ساختار بصری یکپارچه
- قاب گوشی، سایه و عناصر تزئینی خلوت برای تمرکز روی محصول
- خروجی PNG کم‌حجم و شماره‌گذاری‌شده برای آپلود بدون خطا

## بازسازی خروجی

```bash
python3 -m venv .venv
.venv/bin/pip install -r tools/requirements-store-assets.txt
.venv/bin/python tools/build_store_screenshots.py
```
