# 🧠 فاز ۱۱ — تحقیق روانشناسی کودک ۳ تا ۸ سال

> مرجع اجرایی برای طراحی همه بازی‌ها و UI (طبق Montessori و Errorless Learning)

## اصول پایه (برگرفته از Montessori + یادگیری بدون خطا)

1. **یادگیری بدون خطا (Errorless Learning):** در مرحله آموزش اولیه، کودک نباید
   شانس «غلط زدن» داشته باشد؛ گزینه‌ها کم‌کم چالش‌برانگیز می‌شوند. خطاها با
   تشویق اصلاح می‌شوند نه سرزنش.
2. **انگشت به جای کلیک:** هدف لمسی حداقل **۶۴×۶۴ پیکسل** (طبق استاندارد
   Material + توانایی حرکتی ۳ساله‌ها) و فاصله بین اهداف ≥ ۸px.
3. **حلقه پاداش سریع:** بازخورد (صدا + انیمیشن + تشویق) باید < ۱ ثانیه پس از
   عمل بیاید تا کودک ارتباط علت‌ومعلولی را بفهمد.
4. **محدودیت توجه:** فعالیت ۳-۴ ساله ≤ ۵ دقیقه؛ ۵-۶ ساله ≤ ۱۰ دقیقه؛ ۷-۸ ساله ≤ ۱۵ دقیقه.
5. **خطای صبورانه:** هیچ‌وقت «اشتباه!»؛ همیشه «نزدیک بود! دوباره تلاش کن 🌱».
6. **یک کار در هر زمان:** هر صفحه فقط یک هدف اصلی دارد (no split attention).
7. **حرکت و حس:** ویبره نرم + صدا برای موفقیت، حرکت اجباری برای جلب توجه نیست.
8. **کنترل کودک:** کودک همیشه دکمه «برگشت/استراحت» ببیند تا احساس امنیت کند.

## چک‌لیست طراحی (هر صفحه قبل از انتشار)

- [ ] همه اهداف لمسی ≥ 64px
- [ ] فاصله اهداف ≥ 8px
- [ ] بازخورد صوتی/لرزشی < 1 ثانیه
- [ ] هیچ متن سرزنش‌آمیز (فقط تشویق/تلاش مجدد)
- [ ] فقط یک اقدام اصلی در هر فریم
- [ ] دکمه برگشت همیشه در دسترس
- [ ] کنتراست WCAG AA (4.5:1 برای متن)
- [ ] حالت چپ‌دست پشتیبانی می‌شود
