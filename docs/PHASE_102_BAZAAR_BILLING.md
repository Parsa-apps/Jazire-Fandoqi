# فاز ۱۰۲ — اتصال پرداخت کافه‌بازار

## خروجی پیاده‌سازی

- SDK متن‌باز رسمی Poolakey نسخه `2.2.0` به Android اضافه شد.
- `MainActivity` اکنون عملیات `purchase`، `consume` و `restore` را با
  MethodChannel `kudake_iran/billing` به Poolakey متصل می‌کند.
- در release، اعتبارسنجی امضای RSA در خود SDK فعال است. بدون کلید RSA، پرداخت
  با خطای امن رد می‌شود و هیچ دسترسی premium فعال نمی‌گردد.
- هم‌زمانی پرداخت کنترل شده است؛ هنگام پرداخت فعال، درخواست دوم رد می‌شود.
- خرید مصرف‌شدنی تنها پس از `consume` موفق در لایه Dart پاداش می‌دهد.
- حالت debug همچنان sandbox محلی دارد؛ release هرگز از sandbox استفاده نمی‌کند.

## پیکربندی پیش از آزمون واقعی

1. در داشبورد کافه‌بازار، محصولات دقیق `full_version` (خرید غیرمصرف‌شدنی و دائمی) را بسازید.
2. `android/billing.properties.example` را به `android/billing.properties` کپی کنید.
3. کلید عمومی RSA برنامه را در `bazaarRsaPublicKey` قرار دهید. این فایل در Git
   نادیده گرفته می‌شود.
4. APK با همان `applicationId` و certificate انتشار را در کانال sandbox بازار
   بارگذاری کنید.
5. خرید، لغو، قطع اینترنت، بازیابی اشتراک و مصرف محصول را با حساب تست بررسی کنید.

## مرزهای امنیتی

- هیچ کلید خصوصی، token یا رمز signing در کد یا Git ذخیره نمی‌شود.
- نتیجه موفق بدون token در release توسط Dart رد می‌شود.
- Poolakey امضای پاسخ خرید را با کلید عمومی پیکربندی‌شده بررسی می‌کند.
- اعتبارسنجی سمت‌سرور برای اشتراک‌های بلندمدت پیشنهاد می‌شود؛ اپ فعلی کاملاً
  آفلاین است و دسترسی را با پرس‌وجوی مجدد استور در شروع بررسی می‌کند.

## مایکت

این فاز فقط کافه‌بازار را به SDK رسمی Poolakey متصل می‌کند. SDK و قرارداد جاری
مایکت باید جداگانه از مستند رسمی مایکت دریافت و پشت همین MethodChannel به‌صورت
store flavor افزوده شود؛ بدون حساب توسعه‌دهنده و شناسه‌های محصول واقعی، افزودن
حدسی آن قابل‌اعتماد یا امن نیست.

## گرفتن و ثبت کلید RSA مایکت

کلید عمومی مایکت **مخصوص همین برنامه** است و فقط از پنل توسعه‌دهندگان مایکت
تولید می‌شود؛ هیچ‌جای اینترنت منتشر نمی‌شود و قابل حدس‌زدن یا ساختن نیست.

مسیر گرفتن کلید:

1. وارد <https://developer.myket.ir> شوید (حساب توسعه‌دهنده).
2. منوی «برنامه‌ها» → روی باکس برنامهٔ `com.parsaapps.amoozesh_fandoghi`
   آیکن **کلید** را بزنید (اگر برنامه ثبت نشده، اول package name را رزرو کنید؛
   بارگذاری APK لازم نیست).
3. کلید عمومی (RSA / شناسه پرداخت) در یک دیالوگ نمایش داده می‌شود؛ کاملش را کپی کنید.

ثبت کلید در پروژه (با اعتبارسنجی خودکار ساختار کلید):

```bash
tools/set_store_rsa_key.sh myket "MIHNMA0GCSqGSIb3DQEBAQUAA4G7ADCBtwKBrw..."
# یا از کلیپ‌بورد / ورودی استاندارد:
pbpaste | tools/set_store_rsa_key.sh myket -
```

اسکریپت رشته را پاک‌سازی می‌کند (فاصله، خط جدید و هدر PEM)، با `openssl`
بررسی می‌کند که واقعاً یک کلید عمومی RSA سالم باشد و سپس مقابل
`myketRsaPublicKey=` در `android/billing.properties` می‌نویسد. همین اسکریپت با
آرگومان `bazaar` کلید کافه‌بازار را ثبت می‌کند.

تا وقتی این مقدار خالی است، خرید در مایکت غیرفعال می‌ماند و بقیهٔ فروشگاه‌ها
دست‌نخورده کار می‌کنند.
