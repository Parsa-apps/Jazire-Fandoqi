## قوانین بالانس (ضد تورم و ضد قمار)

1. **ضد farming:** تکمیل هر مرحله فقط یک‌بار جایزه دارد (`completeStage` یک‌بار).
2. **ضد قمار:** چرخ شانس همیشه جایزه دارد؛ فقط یک‌بار در روز.
3. **سقف سکه:** ۱۰۰,۰۰۰,۰۰۰ (هیچ‌وقت بیشتر نمی‌شود).
4. **قدرت خرید روزانه:** یک کودک فعال ~۱۰۰-۱۵۰ سکه در روز؛ یک استیکر ویژه = ۱-۲ روز بازی (انگیزه‌ی کافی بدون فشار).
5. **بدون Pay2Win:** فروشگاه فقط تزئینی است؛ هیچ آیتمی توانایی بازی را تغییر نمی‌دهد (فقط ظاهر).
