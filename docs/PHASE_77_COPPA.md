# 🧒 فاز ۷۷ — قوانین کودک (COPPA & ایمنی)

## چک‌لیست COPPA
- [x] سن هدف ۳-۸ سال اعلام شده (پروفایل: فقط سن تقریبی ۳-۱۲)
- [x] بدون تبلیغات شخصی‌سازی‌شده (اصلاً تبلیغات نیست)
- [x] بدون ردیابی/کوکی/آنالیتیکس خارجی
- [x] اطلاعات حداقلی: لقب اختیاری (بدون نام واقعی اجباری) + سن تقریبی
- [x] پرداخت فقط با تأیید بزرگ‌سال (فاز ۶۸ + ۷۳)
- [ ] «دکمه‌ی حذف داده» در پنل والدین (پیشنهاد برای فاز ۹۵)
- [ ] متن COPPA داخل اپ (فاز ۸۰)

## اصول رفتاری داخل اپ
- هیچ‌وقت دیتای کودک ارسال نمی‌شود (ممیزی فاز ۴۹/۶۳)
- بدون چت باز با غریبه‌ها: «دوست خیالی فندقی» فقط قانون‌محور است
- بدون لینک خروجی به سایت‌های دیگر از داخل بخش کودک

## مسئولیت والدین
- پنل والدین با PIN محافظت می‌شود (فاز ۶۱)
- محدودیت زمانی روزانه (فاز ۶۲)
- گزارش مهارت‌ها و پیشنهاد هوشمند (فاز ۴۷)
