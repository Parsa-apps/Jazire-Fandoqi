# 🚀 فاز ۹۳ — کمپین لانچ

## ویدیو ۳۰ ثانیه‌ای (اسکریپت)
- ۰-۵s: فندقی می‌پرد وسط صفحه: «سلام! من فندقی‌ام!»
- ۵-۱۵s: مونتاژ سریع بازی‌ها (حباب، الفبا، حیوانات، نقاشی)
- ۱۵-۲۵s: متن بزرگ: «آفلاین، بدون تبلیغ، فارسی»
- ۲۵-۳۰s: «دانلود کن!» + لوگو

## بنر
- پس‌زمینه سبز-آبی گرادیان + فندقی + «آموزش فندقی — یادگیری شاد»

## متن کانال تلگرام پارسااپس
«🎉 آموزش فندقی نسخه ۵ منتشر شد! ۵۰ مرحله، ۳۰ حیوان ایران، ۱۰ داستان تعاملی — کاملاً آفلاین و امن برای کودک شما. دانلود از کافه‌بازار 💚»

## زمان‌بندی
- ۳ روز قبل: تیزربازی (teaser)
- روز لانچ: پست اصلی + ویدیو
- ۷ روز بعد: پست رضایت والدین + ریتینگ
