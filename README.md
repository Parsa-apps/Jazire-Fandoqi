### ✅ موارد سخت‌گیرانه‌ی نسخه ۴.۱
- onboarding کوتاه با لقب اختیاری و بازه سنی؛ هیچ اطلاعات شخصی یا شبکه‌ای لازم نیست
- مسیرهای نقشه واقعاً به بازی درست وصل هستند؛ مقصد ناشناخته دیگر به‌صورت تصادفی ستاره‌گیری نیست
- آکادمی حرفه‌ای الفبا با آموزش دیداری، تمرین نوشتن روی راهنما و ارزیابی محلی
- فعالیت‌های محلی متنوع: آکادمی الفبا، آزمون موضوعی، نقاشی، حافظه، حباب‌ترکان و ستاره‌گیری
- فندقیِ بزرگ به‌عنوان مربی، راهنما و داور مرکزی؛ پیام‌های آموزشی و بازخورد درست/غلط به‌صورت حباب پاپ‌آپ در همه بازی‌ها
- ذخیره‌سازی مقاوم در برابر خرابی/هم‌زمانی، migration کلیدهای نسخه‌های قبل و پاداش idempotent مرحله‌ها
- کنترل والدین با gate، محدودیت زمان روزانه و اجرای واقعی محدودیت در ورودی بازی‌ها
- آپدیت زنده داشبورد/پروفایل بعد از برگشت از بازی و lazy loading تب‌های سنگین
- پرداخت release بدون رسید/توکن معتبر دسترسی نمی‌دهد؛ خرید مصرف‌شدنی قبل از اعطای موجودی consume می‌شود
- تصویرسازی‌های WebP اختصاصی برای حافظه، میوه‌ها، حیوانات، رنگ‌ها، شکل‌ها، شغل‌ها و بدن
- حذف وابستگی‌های بلااستفاده برای کاهش حجم و سطح حمله

### ⚠️ چک‌لیست پیش از ارسال به بازار
1. در CI این دستورات باید بدون خطا اجرا شوند: `flutter analyze`، `flutter test`،
   `flutter build apk --release` و `flutter build appbundle --release`.
2. ماژول Native کانال `kudake_iran/billing` را با SDK رسمی کافه‌بازار/مایکت
   پیاده‌سازی و در محیط sandbox با حساب تستی آزمایش کنید.
3. شناسه محصولات، قیمت‌ها، متن حریم خصوصی، سن هدف و محتوای آموزشی را با پنل
   بازار و قوانین جاری تطبیق دهید. هیچ ادعای خرید یا اشتراک بدون تایید استور
   نباید فعال شود.
4. روی حداقل یک گوشی ضعیف، یک گوشی کوچک، حالت RTL، حالت شب، قطع اینترنت،
   بازگشت از پس‌زمینه و چرخش صفحه تست دستی انجام دهید.
