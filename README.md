## قابلیت‌ها

### یادگیری و بازی

- راهنمای تصویری شروع و پیشنهاد محترمانه و اختیاری برای تکمیل پروفایل کودک؛ بدون آزمون و حساب کاربری
- ۲۰ آواتار کودکانهٔ داخلی برای پروفایل؛ بدون دسترسی به گالری، دوربین یا عکس‌های شخصی
- آکادمی الفبا با آموزش دیداری، تمرین نوشتن روی راهنما و ارزیابی محلی
- کتابخانهٔ یادگیری قابل دسترس از دروازهٔ اصلی: دانشنامه ۳۰ حیوان ایران، اعداد ۱ تا ۲۰، شغل‌ها، مفاهیم و SEL
- آزمون‌های موضوعی برای الفبا، اعداد، رنگ‌ها، حیوانات، شکل‌ها، میوه‌ها، بدن،
  شغل‌ها و احساسات
- بازی حافظه با کارت‌های تصویری اختصاصی
- نقاشی آفلاین با قلم، پاک‌کن، رنگ، استیکر و Undo/Redo
- بازی حباب‌ترکان با حروف، اعداد و رنگ‌ها
- بازی ستاره‌گیری با موتور Flame، سبد قابل جابه‌جایی، امتیاز و جان
- نقشه مرحله‌ای با مسیر واقعی و اتصال هر مرحله به بازی درست

### فندقی، مربی و راهنما

- کاراکتر جدید فندقی با تصویر شفاف و بدون پس‌زمینه یا هاله سفید
- حضور فندقی در Splash، راهنمای شروع، داشبورد و بازی‌ها
- حباب پیام سراسری برای آموزش، تشویق، داوری و بازخورد پاسخ‌ها
- امکان جابه‌جایی فندقی با حفظ نقطه لمس و جلوگیری از خروج از لبه صفحه
- حرکت حباب متن همراه با فندقی هنگام Drag
- انیمیشن ورود، شناورشدن و بازخوردهای مناسب کودک

### پایداری و امنیت

- ذخیره‌سازی محلی با `SharedPreferences` و بازیابی مقاوم در برابر داده خراب
- migration کلیدهای نسخه‌های قبلی و جلوگیری از پاداش تکراری مرحله‌ها
- بکاپ و بازیابی آفلاین `.parsa` با AES-256-GCM از پنل والدین
- کنترل والدین با دروازه ورود، محدودیت زمان روزانه و rollover درست مأموریت‌ها
- بازی کاملاً آفلاین؛ اطلاعات کودک به شبکه ارسال نمی‌شود
- فعال‌سازی خرید در نسخه release فقط پس از دریافت رسید/توکن معتبر از استور
- مصرف خریدهای مصرف‌شدنی قبل از اعطای موجودی
- پشتیبانی از حالت روشن، تاریک و رابط راست‌به‌چپ

## اجرا و بررسی

پیش‌نیاز: Flutter stable نسخه ۳.۲۴.۳ یا جدیدتر و Java 17 برای بیلد Android.

```bash
flutter pub get
flutter run
```

برای اجرای کامل بررسی و بیلد از اسکریپت پروژه استفاده کنید:

```bash
./build.sh                 # analyze، test و APK debug
BUILD_MODE=release ./build.sh
```

دستورات اصلی پایپ‌لاین:

```bash
flutter analyze
flutter test
flutter build apk --release
flutter build appbundle --release
```

## چک‌لیست پیش از انتشار

1. همه دستورات analyze، test و build بدون خطا اجرا شوند.
2. SDK بومی کانال `kudake_iran/billing` با SDK رسمی کافه‌بازار یا مایکت
   پیاده‌سازی و در sandbox با حساب تستی بررسی شود.
3. شناسه محصولات، قیمت‌ها، متن حریم خصوصی، سن هدف و محتوای آموزشی با پنل استور
   تطبیق داده شود.
4. روی گوشی ضعیف و کوچک، رابط RTL، حالت شب، قطع اینترنت، بازگشت از پس‌زمینه و
   چرخش صفحه تست دستی انجام شود.
5. پیش از انتشار، keystore واقعی در `android/key.properties` و کلید RSA بازار در `android/billing.properties` تنظیم شوند؛ ساخت release بدون امضای واقعی متوقف می‌شود.
