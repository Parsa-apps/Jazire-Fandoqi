# تم نقشهٔ جزیرهٔ فندقی — منابع طراحی

تم اصلی برنامه یک نقشهٔ عمودیِ اسکرول‌شونده است. برخلاف نسخهٔ قبلی، نقشه
**یک تصویر تخت نیست**؛ هر عنصر جداگانه تولید و پس‌زمینه‌اش شفاف شده تا در
Flutter بتوان هرکدام را مستقل انیمیت کرد (شناور بودن، تاب خوردن، فشرده شدن
هنگام لمس).

## پوشه‌ها

| مسیر | چیست |
|---|---|
| `parts_cutout/` | مسترهای شفاف و تمام‌رزولوشن (منبع اصلی) |
| `full_map_v3.png` | ترکیب‌بندی تأییدشده — فقط مرجع بصری، در برنامه استفاده نمی‌شود |
| `make_transparent.py` | حذف پس‌زمینهٔ سفید از رندرهای خام |

خروجی نهایی در `assets/theme_map/` است (۹ فایل، حدود ۳۳۰ کیلوبایت).

## ساخت دوبارهٔ دارایی‌های نهایی

```bash
python3 design/theme_map/make_transparent.py     # parts/ → parts_cutout/
```

سپس هر master با `LANCZOS` کوچک و کوانتیزه می‌شود:

| دارایی | عرض نهایی |
|---|---|
| جزیره‌ها | ۴۴۰ |
| `bridge.png` | ۷۲۰ |
| `sign_board.png` | ۵۶۰ |
| `hero_fandoq.png` | ۴۲۰ |

```python
im = im.resize((W, H), Image.LANCZOS)
im.convert('RGBA').quantize(colors=200, method=Image.FASTOCTREE).save(out, optimize=True)
```

## نکتهٔ مهم دربارهٔ متن

مولد تصویر فارسی نمی‌نویسد، پس تابلوها و دکمه‌های شیشه‌ای **عمداً خالی**
تولید شده‌اند. متن با ویجت فارسی دقیقاً روی همان‌ها می‌نشیند؛ مختصات هر
دکمه در `PillRect.byAsset` داخل
`lib/features/home/widgets/island_map/island_node.dart` است. اگر دارایی‌ای
دوباره تولید شد، آن کسرها باید دوباره اندازه‌گیری شوند.
