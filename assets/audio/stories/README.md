# 🎙️ صدای بچگانه داستان‌ها — راهنما

این پوشه شامل فایل‌های صوتی پیش‌تولید شده برای هر صفحه از ۱۰ داستان کودکانه است.

## مشخصات فنی صدا
- **زبان:** فارسی روان بدون لهجه (fa-IR)
- **صدا:** بچگانه حرفه‌ای — زن کودک ۸-۱۰ ساله، لحن شاد و قصه‌گو
- **لحن:** کودکانه، گرم، شمرده، مناسب برای کودکان ۳-۸ سال
- **تولید:** هوش مصنوعی TTS حرفه‌ای (voice-00)
- **فرمت:** MP3، 24kHz، مونو

## نام‌گذاری
```
story_{id}_page{number}.mp3
```
مثال:
- `story_bear_friendship_page1.mp3` — فندقی و خرس مهربان، صفحه ۱
- `story_golden_butterfly_page2.mp3` — پروانه طلایی، صفحه ۲

## نحوه پخش در اپ
- `StoryAudioService` اول تلاش می‌کند فایل پیش‌ضبط شده را با `just_audio` پخش کند (صدای بچگانه واقعی)
- اگر فایل نبود، به صورت خودکار به `AudioService.speak()` (TTS سیستم با pitch کودکانه) fallback می‌کند
- هیچ‌یک از داستان‌ها بدون صدا نمی‌ماند

## تولید مجدد
```bash
dart run tools/generate_story_audio.dart
```
یا از طریق سرویس Arena:
- `add_voice` با زبان `fa` و جنسیت `feminine`
- سپس `generate_speech` برای هر صفحه با همان `voice_id`
