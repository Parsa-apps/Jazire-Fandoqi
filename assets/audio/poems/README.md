# ضبط‌های خوانش شعر (Poem Recordings)

فایل‌های ضبط‌شدهٔ خوانش بچگانهٔ شعرها اینجا قرار می‌گیرند.

## نام‌گذاری (الزامی)

```
assets/audio/poems/poem_<id>.mp3
```

`<id>` همان `id` هر شعر در
`lib/core/learning_content/poems_data.dart` است:

| id          | نام شعر        | فایل مورد انتظار            |
|-------------|----------------|-----------------------------|
| ball        | توپ قلقلی      | `poem_ball.mp3`             |
| rain        | باران بهاری    | `poem_rain.mp3`             |
| cat         | گربه کوچولو    | `poem_cat.mp3`              |
| mother      | دست‌های مادر   | `poem_mother.mp3`           |
| star        | ستاره‌ها       | `poem_star.mp3`             |
| spring      | بهار آمد       | `poem_spring.mp3`           |
| butterfly   | پروانه رنگی    | `poem_butterfly.mp3`        |
| fandoghi    | فندقی شاد      | `poem_fandoghi.mp3`         |

## مشخصات پیشنهادی ضبط

- صدای گویندهٔ کودک/بچگانه، لحن شاد و آهنگین، فارسی روان بدون لهجه
- MP3، مونو، ۴۴.۱kHz، ۹۶–۱۲۸kbps، حداکثر ~۱.۵ مگابایت برای هر شعر
- بدون افکت موسیقی پس‌زمینه (موسیقی پس‌زمینه فقط در صفحه اصلی پخش می‌شود)
- سکوت ابتدا/انتها کمتر از ۳۰۰ میلی‌ثانیه باشد تا پخش بی‌درنگ بماند

## رفتار وقتی فایل وجود نداشته باشد

صفحهٔ شعر (`PoemReaderScreen`) به‌جای خطا، متن را با TTS فارسیِ
دستگاه می‌خواند؛ پس هیچ شعری بدون صدا نمی‌ماند. به‌محض اضافه‌شدن
فایل ضبط‌شده با همین نام‌گذاری، همان فایل به‌صورت خودکار اولویت
می‌یابد (نیازی به تغییر کد نیست).
