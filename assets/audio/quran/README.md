# ضبط‌های تلاوت قرآن کودک (Quran Recitations)

فایل‌های تلاوت رسمی سوره‌های کوتاه اینجا قرار می‌گیرند.

## نام‌گذاری (الزامی)

```
assets/audio/quran/quran_<id>.mp3
```

`<id>` همان `id` سوره در
`lib/core/learning_content/quran_data.dart` است:

| id       | سوره      | تعداد آیه | فایل مورد انتظار          |
|----------|-----------|-----------|---------------------------|
| fatiha   | حمد       | ۷         | `quran_fatiha.mp3`        |
| ikhlas   | اخلاص     | ۴         | `quran_ikhlas.mp3`        |
| falaq    | فلق       | ۵         | `quran_falaq.mp3`         |
| nas      | ناس       | ۶         | `quran_nas.mp3`           |
| kawthar  | کوثر      | ۳         | `quran_kawthar.mp3`       |
| asr      | عصر       | ۳         | `quran_asr.mp3`           |
| nasr     | نصر       | ۳         | `quran_nasr.mp3`          |
| fil      | فیل       | ۵         | `quran_fil.mp3`           |

## مشخصات پیشنهادی ضبط

- تلاوت صحیح و تجویدیِ قاری مسلط، با لحن آرام و مناسب کودک
- MP3، مونو، ۴۴.۱kHz، ۱۲۸kbps
- شامل بسمهٔ ابتدای سوره (به‌جز حمد که بسمه آیهٔ اول است)
- بدون موسیقی پس‌زمینه و بدون افکت

## خط‌مشی مهم: هیچ fallback خودکاری وجود ندارد

برخلاف شعر، برای متن عربیِ قرآن هرگز به TTS دستگاه نمی‌افتیم تا
تلفظ نادرست یا لحن نامناسب پخش نشود. اگر فایل تلاوت هنوز باندل
نشده باشد، صفحه فقط متن عربی و معنی فارسی را نشان می‌دهد و
دکمهٔ صدا وضعیت «به‌زودی» می‌گیرد. به‌محض قرارگرفتن فایل با همین
نام‌گذاری، تلاوت خودکار فعال می‌شود (بدون نیاز به تغییر کد).
