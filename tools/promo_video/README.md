# Promo video generator — جزیره فندقی

Renders a fully animated app promo video from the project's own artwork.
Everything is generated by code, so the video can be re-rendered at any time
(new logo, new duration, new aspect ratio) without any video editor.

## Output

| File | Size | Use |
| --- | --- | --- |
| `promo/jazire_fandoqi_promo_portrait.mp4` | 1080×1920, 30 fps | Cafe Bazaar / Myket app page, Instagram Reels, Shorts |
| `promo/jazire_fandoqi_promo_landscape.mp4` | 1920×1080, 30 fps | YouTube, website, TV / press kit |

Duration ≈ 32 s, H.264 High profile + AAC 192 kbps, `+faststart` (streams
instantly), yuv420p (plays everywhere).

**No on-screen text anywhere.** The only lettering visible is whatever is baked
into the logo itself. This keeps the video usable on every store and in every
locale, and avoids review rejections for unreadable/duplicated text.

## Storyboard

| # | Scene | Beat |
| --- | --- | --- |
| 1 | Island wake-up | Logo drops in with an elastic settle + sparkle burst; Fandoqi pops up amazed |
| 2 | Worlds | Three glass world-bubbles float in while Fandoqi bounces between them |
| 3 | Games | 9 candy-coloured game tiles pop in on a diagonal stagger, then breathe |
| 4 | Stories & lullabies | Story artwork glides past in a soft 3D carousel |
| 5 | Rewards | Stars fly into the trophy, medal + badge slide in, confetti explodes |
| 6 | End card | Logo returns with a halo, light sweep and a proud Fandoqi — the install beat |

Scenes cross-dissolve with a subtle push-in (0.55 s), and the whole film fades
up from and down to black.

## Audio

- **Music** — synthesised in `audio_mix.py` with numpy: marimba arpeggios,
  plucked lead, soft bass, claps and shakers over a I–V–vi–IV progression at
  116 BPM, with the arrangement building in energy toward the end card.
  Nothing is sampled from a third party, so it is safe to publish.
- **SFX** — the app's own `assets/audio/sfx/*.wav` cues, timed to the animation.
- **Voice-over** — Persian, cheerful, child-friendly. Music and SFX duck
  automatically under the narration.

## Usage

```bash
pip install pillow numpy imageio-ffmpeg

# both aspect ratios, full quality
python3 tools/promo_video/render.py --preset both

# fast preview while iterating (quarter size, 10 fps)
python3 tools/promo_video/render.py --preset portrait --scale 0.25 --fps 10

# use a different logo file
python3 tools/promo_video/render.py --preset both --logo path/to/logo.png
```

Useful flags: `--fps`, `--crf` (lower = better quality), `--workers`,
`--outdir`, `--audio` (reuse an already-built mix — handy when rendering the
second aspect ratio).

## Files

| File | Role |
| --- | --- |
| `engine.py` | Easing curves, sprite compositing, glow/vignette, white-background cut-out, particle systems |
| `scenes.py` | The six scenes and the shared layout helpers (all positions are fractions of the canvas, so both aspect ratios work from one codebase) |
| `audio_mix.py` | Music synthesis, SFX + voice-over cue sheet, ducking and limiting |
| `render.py` | Timeline, cross-fades, multiprocess frame rendering, ffmpeg muxing |

## Replacing the voice-over

Voice clips live in `.tmp_build/vo/` and are referenced by
`audio_mix.vo_cues()` as `(filename, start_second, gain)`. Drop in new
recordings with the same names, or edit the cue list, then re-render.

## Notes

- `promo/` and `.tmp_build/` are git-ignored — the artwork ships in the repo,
  the multi-megabyte renders do not.
- Frame rendering is CPU-bound and parallel; on a 2-core box a full 1080×1920
  pass takes roughly 8–9 minutes.
